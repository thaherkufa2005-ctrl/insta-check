# InstaCheck — كاشف الحسابات الوهمية على إنستغرام

🌐 **الموقع المباشر:** https://thaherkufa2005-ctrl.github.io/insta-check/

أداة ويب تحلل حسابات إنستغرام وتقدّر احتمال أن يكون الحساب وهمياً (Fake Account)،
عبر محرك تحليل إحصائي يفحص أكثر من 12 مؤشراً سلوكياً.

Instagram fake-account detector — a heuristic scoring engine that estimates
the probability an account is fake, based on 12+ behavioral signals.

## المؤشرات (Signals)

**تحليل اسم المستخدم:**
- أرقام طويلة بنهاية الاسم
- نسبة الأرقام إلى الحروف
- حروف مكررة بشكل عشوائي
- كثرة النقاط والشرطات
- طول الاسم غير الطبيعي
- تركيب حروف عشوائي (بدون حروف علة)

**تحليل بيانات الحساب (إدخال يدوي حالياً):**
- نسبة المتابَعين إلى المتابِعين
- عدد المنشورات مقابل المتابعين
- عمر الحساب ووتيرة النشر
- الصورة الشخصية والنبذة
- معدل التفاعل (الإعجابات / المتابعين)
- علامة التوثيق

## التقنيات

React 19 · TypeScript · Vite · Tailwind CSS · واجهة عربية RTL

## التشغيل محلياً

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # نسخة الإنتاج في dist/
```
